# Changelog

## 1.0.0 — 2026-11-01

First public release of SubSnipe.

- Import bank and card statements in the browser (CSV with column detection and manual mapping, PDF text extraction when the file has a real text layer).
- Detect monthly, quarterly, and yearly subscriptions, price hikes, trial-to-paid conversions, duplicate plans, and forex or markup fees.
- India-first merchant catalog and cancel guides, with common international services.
- Keep / Cancel / Unsure triage, a yearly total, and a PNG summary that omits merchant names unless you opt in.
- Optional IndexedDB save and a wipe control. Installable offline shell, strict content security policy, no network calls.
