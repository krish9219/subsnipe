merchantId: xbox
title: Cancel Xbox Game Pass
officialUrl: https://account.microsoft.com/services
---

Game Pass and Xbox Live Gold (now included with Game Pass) are cancelled from the Microsoft account that pays.

1. Open account.microsoft.com/services and sign in.
2. Select Xbox Game Pass or the Xbox subscription named on your statement.
3. Choose Manage, then Cancel, and confirm recurring billing is off.
4. If a code or a console store in another region sold it, the services page still shows the plan tied to that Microsoft account.

Note: Cloud saves generally remain. Games included with Game Pass leave your library when the membership ends, except titles you bought.
